# HealthAgent 模块一测试作业

本次测试注册登录、个人信息和血压记录。用例30条，使用等价类和场景法；另有3条缺陷专项检查。

## 主要文件

- 测试报告_模块一.docx：测试方法、结果和分工。
- 测试用例清单_模块一.xlsx：30条用例。
- 缺陷清单_模块一.docx：3个问题及修复结果。
- HealthAgent_模块一成果汇报.pptx：10页汇报。
- 成果汇报纲要与演示视频脚本.md：录屏顺序。
- 执行结果、缺陷证据：必要日志和专项脚本。

## 怎么运行

先按仓库根目录README安装backend/.venv依赖，再在本文件夹打开终端：

```bash
bash run_module1_tests.sh
bash 缺陷证据/run_defect_checks.sh
```

第一条运行30条功能用例，第二条运行3条缺陷专项，结果分开统计。源码位于本仓库backend中。
