## 怎么运行

先安装backend/.venv依赖，在仓库根目录的PowerShell运行：

```powershell
backend/.venv/Scripts/python.exe 模块一作业交付包/第二批_陆京超/run_checks.py module1
backend/.venv/Scripts/python.exe 模块一作业交付包/第二批_陆京超/run_checks.py defects
```

第一条运行30条功能用例，第二条运行3条缺陷专项，结果分开统计。源码位于本仓库backend中。

macOS/Linux将解释器路径换为backend/.venv/bin/python，也可在本文件夹运行原有run_module1_tests.sh和缺陷证据/run_defect_checks.sh。
