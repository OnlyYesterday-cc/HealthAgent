## 运行

沿用已安装的backend/.venv。在仓库根目录PowerShell运行：

```powershell
backend/.venv/Scripts/python.exe 模块二作业交付包/run_checks.py
```

macOS/Linux替换为backend/.venv/bin/python。首次安装使用python -m venv backend/.venv及backend/.venv/Scripts/python.exe -m pip install -e './backend[dev]'。

当前入口仅运行已实现的5条模块二用例，独立保存日志、JUnit XML、版本和关键文件哈希。存在失败时返回非零，不能把计划中的20条写成已执行。每次执行新建时间戳目录，支持--output-dir指定目录。

测试使用SQLite内存库和测试签名密钥。构造异常但签名合法的JWT用于输入健壮性检查，不使用正式密钥，也不能据此声称攻击者无需密钥就能伪造令牌。
